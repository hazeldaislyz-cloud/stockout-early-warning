Which facilities a county pharmacist should follow up next month, and where stock can be moved before it expires.

Simulated data: 48 facilities in 6 counties. The supply pattern is calibrated against real national warehouse issue records, but no facility, figure or location here is real. Every output is an estimate for a pharmacist to check, not an instruction.

How good are the alerts?

      
A county team can only follow up so many facilities. So the test is: of the top N alerts each month, how many really ran out? Tested on 12 months the model never saw.
